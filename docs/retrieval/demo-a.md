# 星河读书活动

星河读书活动将在周三下午三点开始，地点是图书馆二楼。活动联系人是林老师，报名截止时间是周二中午。请参加活动的同学携带纸质笔记本，不需要携带实验器材。

活动分成三个环节：先安静阅读，再分组交流，最后分享读书笔记。每位同学选择一段自己喜欢的文字，说明选择理由。分享时先读出原文，再介绍自己的理解；其他同学认真倾听，在发言结束后提出问题。

阅读期间请保持安静，把手机调成静音。需要借阅图书的同学按照图书馆的正常借阅流程办理。活动结束前，各组整理桌面，将椅子放回原位，并检查随身物品。

读书笔记可以记录书名、作者、所选段落和自己的问题。无需追求篇幅，重点是准确记录原文与自己的理解。遇到不认识的词语，可以先在笔记中标注，再与同学交流。

活动只面向本班同学。报名后如果临时无法参加，请提前向林老师说明。老师会根据报名人数安排分组，每组轮流安排一位记录员，负责整理大家提出的问题，便于下一次阅读活动继续讨论。
